# Calculator Application

A simple and responsive calculator application built using **HTML**, **CSS**, and **JavaScript**. This project demonstrates basic arithmetic operations and includes additional features like percentage and square root calculations. The calculator is styled with a modern design and interactive button effects.

## Features

- **Basic Arithmetic Operations**: Perform addition, subtraction, multiplication, and division.
- **Advanced Operations**:
  - Square root (`√`)
  - Percentage (`%`)
- **Clear and Delete Functionality**:
  - **AC**: Clears the entire input.
  - **Del**: Deletes the last character from the input.
- **Keyboard Support**: Use your keyboard to input numbers and operators.
- **Responsive Design**: Works seamlessly on different screen sizes.
- **Error Handling**: Displays "Error" for invalid operations.
